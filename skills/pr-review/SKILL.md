# PR Review

1. Identify the PR from the request or repository context. Clarify an ambiguous target.
2. Read the PR description, diff, relevant surrounding code, applicable project instructions, and supplied task context.
3. Check correctness, security, maintainability, and alignment with agreed scope. Use relevant existing evidence and targeted checks as needed.
4. Report actionable findings with file/line references and their impact. Distinguish defects, optional suggestions, and uncertainty. State when no issues were found and mention meaningful verification limits.

Return the review in chat. When posting is requested, use the repository's host tooling and confirm success.

Apply project-specific review and merge policy.
